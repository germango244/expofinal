# Carpetas de audios

Coloca aquí los archivos .mp3 o .wav que usarán los botones de voz de las lecciones.

Estructura recomendada:

- audios/letters/
  - a.mp3
  - e.mp3
  - i.mp3
  - o.mp3
  - u.mp3
  - vowel_a.mp3
  - vowel_e.mp3

- audios/vowels/
  - a.mp3
  - e.mp3
  - i.mp3
  - o.mp3
  - u.mp3

- audios/syllables/
  - ca.mp3
  - ba.mp3
  - ma.mp3
  - cat.mp3
  - bat.mp3
  - mat.mp3
  - hat.mp3

- audios/words/

  - flower.mp3

- audios/sentences/
  - the_girl_drinks_milk.mp3
  - the_boy_plants_the_seed.mp3
  - he_waters_the_plant_every_day.mp3
  - the_plant_grows_happy.mp3
  - dixi_loves_learning.mp3

Recomendación:
- usa archivos cortos y claros
- mejor .mp3
- nómbralos en minúsculas y sin espacios
- si quieres, cada botón puede apuntar a un archivo distinto según la palabra o sonido
